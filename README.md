# my-retro-desktop
A game where you have a desktop with all my game projects on it

# Project idea

A retro-styled desktop simulation game built in Godot

## Features
* Simulated 2000s-era Operating System
* Multiple built-in games

## Tech Stack
* **Engine:** Godot 4
* **Language:** GDScript

## How to Run
1. Download Godot 4.
2. Clone this repository.
3. Import `project.godot` into the Godot project manager.
4. Press F5 to run!
